# OZR POS — Tanıtım Sitesi

[OZR POS](https://github.com/EmirhanOzer07/OZR-Pos) market satış programının müşteriye dönük tanıtım sitesi.

- Tamamen statik: HTML + CSS + vanilla JS, framework yok, çerez yok.
- Yayın: GitHub Pages (main branch, root).
- En son sürüm bilgisi ve indirme linki GitHub Releases API'den dinamik çekilir — release çıkınca sitede güncelleme gerekmez.
- İletişim ayarları (WhatsApp numarası, e-posta) tek yerden: `assets/js/main.js` başındaki sabitler.

## Yerelde önizleme

Herhangi bir sunucu gerekmez — `index.html`'e çift tıklamak yeterli.
